	\section{Introduction}\label{Intro}
		
		The paper is introduces a method for time series classification. The \emph{time series} is a finite sequence of scalar values $x(t_i)= \{ x_{t_1}, \ldots, x_{t_n} \}$ with variable length defined at particular times $t_1, \ldots, t_n \in \mathbb{R}$. The \emph{multivariate} time series is a sequence of vector values $\bx(t_i)= \{\bx_{t_1}, \ldots, \bx_{t_n}\}$ where $\mathbb{R}^d$. This is equal to having $d$ time series with the same times. Everywhere further we assume time series to be multivariate in general. From theoretical point of view it is convenient to assume time series values $\bx_{t_i}$ to be \emph{random vectors}. Time series have an associated \emph{class label} $y \in 1 \ldots K$ that is also random in general. Here $K$ is the number of classes. A \emph{classifier} is a map $\delta(\bx(t_i))$ that associates any time series with a class label. We will seek to obtain a "good" classifier in some sense defined later.
		
		% Methods from literature review
		There are many methods for time series classification in the literature. \emph{Distance-based} approaches rely on measuring similarity between time series using distance metrics. The metric can be defined using Dynamic Time Warping~\cite{dtw} and the k-Nearest-Neighbors (k-NN) classifier can be used then~\cite{knn_dtw}. \emph{Feature-based} approaches extract finite set of statistical~\cite{stat_feat_1, stat_feat_2} or spectral~\cite{fouirer_feat} features from time series for further classification. \emph{Deep learning} approaches uses neural networks to automatically learn time series features from raw train data. Convolutional neural networks~\cite{application_eeg_1, application_eeg_2}, recurrent neural networks (RNN)~\cite{lstm_feat} or their combination~\cite{application_sound_1, application_hac, application_weather} are designed to process sequential data like time series.
		
		In the paper we assume particular model behind time series - \emph{dynamical system}. By that we mean the time-invariant \emph{ordinary differential equation (ODE)} of the form
		\begin{equation}\label{eq:series_dyn}
			\begin{cases}
				\frac{d}{dt} \bbx(t) = f(\bbx), \\
				\bbx(0) = \bbx_0,
			\end{cases}
		\end{equation}
		where $\bbx \in M$, $f(\bx): M \to M$ is a \textit{vector field}, $\bbx_0$ is a \textit{starting point}, $M$ is a differentiable manifold in general. We consider vector fields are not arbitrary but belong to some normed space $f \in (\mathcal{F}(M), \lVert \cdot \rVert)$. To find a solution $\bbx(t)$ satisfying (\ref{eq:series_dyn}) on some time interval $t \in [0, T]$ is to solve an \emph{initial value problem (IVP)}. We also denote IVP as $\bbx(t | \bbx_0, f)$ and call it \textit{phase trajectory}. The IVP is also equivalent to the following integral equation
		\begin{equation}\label{eq:series_dyn_int}
			\bbx(t | \bbx_0, f) = \bbx_0 + \int\limits_0^t f\big(\bbx(s | \bbx_0, f)\big) ds.
		\end{equation}
		Under some regularity conditions on $f$ the solution is unique~\cite{Wiggins2003}. We associate $K$ different vector fields $f_j, \  j \in 1, \ldots, K$ with each series class. The series values are the noisy phase trajectories
		\begin{equation}\label{eq:series_def}
			\bx(t_i) = \bbx(t_i) + \beps(t_i),
		\end{equation}
		where $\beps(t_i)$ is a random noise process. Its values $\beps_{t_i}$ are i.i.d.random vectors (mutually for all classes and any times) having
		\begin{equation}\label{eq:noise_conditions}
			\mathbb{E}[\beps_{t_i}] = 0, \  \text{Cov}(\beps_{t_i}) = R \text{ where } \lVert R \rVert_2 \le \sigma^2 < \infty.
		\end{equation}
		Here $R$ is covariance matrix, $ \lVert R \rVert_2$ is matrix spectral norm. Therefore $\mathbb{E}[\bx(t_i)] = \bbx(t_i)$ and $\text{Cov}[\bx(t_i)] = R$. In general, the classifier must account for both the deterministic component $\bbx(t_i)$ and the noise component $\beps(t_i)$ of the series. We will later show that under some conditions there is an asymptotically accurate classifier that would not rely on the noise. Then we will discard these condition and will introduce more general classifier. Moreover, we will be able to adapt the classifier to the more general dynamical system described by the \emph{stochastic differential equation (SDE)} \cite{bibid} of the form
		\begin{equation}\label{eq:series_sde_dyn}
			\begin{cases}
				d\bbx(t) = f(\bbx)dt + G dW(t), \\
				\bbx(0) = \bbx_0,
			\end{cases}
		\end{equation}
		where $W(t)$ is a $m$-dimensional Brownian motion,  $G$ is a $d \times m$ constant diffusion matrix, unique for each class. Phase trajectories $\bbx(t)$ are \emph{random processes} in this model. The definition of the IVP translates straightforwardly for the SDE. The IVP solution is unique under some regularity conditions on $f$~\cite{bibid}.
		
		Our approach can be extended for the less direct connection between observed time series and the phase trajectories (\ref{eq:series_def}). Imagine the connection is given by some \emph{observation map} $\alpha: M \to \mathbb{R}^d$ such that
		\begin{equation}\label{eq:takens_series}
			\bx(t_i) = \alpha(\bbx(t_i)) + \beps(t_i),
		\end{equation}
		where $M$ has dimension $k \not= d$ in general. We would like to reconstruct the $\bbx(t_i)$ from the $\bx(t_i)$ to build a classifier. The reconstruction will be based on building an \emph{embedding} of the manifold $M$. In general, an embedding is a smooth map $\phi: M \to N$ into another manifold $N$ that is a diffeomorphism onto its image $\phi(M)$. It follows that phase trajectories $\bbx(t) \subset M$ and $\phi(\bbx(t)) \subset\phi(M)$ are basically identical (more strictly, diffeomorphic). To reconstruct the phase trajectories we need to build $\phi(\bbx(t_i))$ from the observed time series $\bx(t_i)$. One way to archive this is the Whitney Embedding Theorem~\cite{whitney}. If $\alpha$ is a generic map~\cite{what is generic} from $M$ to $\mathbb{R}^{2k + 1}$ then $\alpha = \phi$ and therefore $\bx(t_i) = \phi(\bbx(t_i))$. This is basically the original connection (\ref{eq:series_def}) but with the diffeomorphic phase trajectories instead of the original one. However, this approach requires an excessive $2k + 1$ number of time series even when $k$ is rather small. Another approach is the Takens embedding theorem~\cite{takens2006detecting}. It requires only one observed scalar time series $x(t_i)$. If $\alpha$ is a generic map from $M$ to $\mathbb{R}$ then the embedding is given by the map
		\begin{equation*}
			\phi(\bbx) = \big( \alpha(x), f(\alpha(x)), \ldots, f^m(\alpha(x)) \big),
		\end{equation*}
		where $m > 2k$. Substituting $\bbx(t_i)$ gives us $\phi(\bbx(t_i)) = \big( x(t_i), x(t_{i-1}), \ldots, x(t_{i-k})\big)$ which we call \emph{delay vector}. Illustration of the Takens theorem is on the Fig.~\ref{fig:takens}. The delay vectors form noisy diffeomorphic phase trajectory because $x(t_i)$ is iself noisy. So they are basically identical to $\bx(t_i)$ from (\ref{eq:series_def}). Further, we would not differentiate reconstructed phase trajectories and the original one.

		\end{figure}

		% Relevance
		Our time series' model can be applied to many real-word classification problems. For example, in medicine an electroencephalogram (EEG) is a direct, macroscopic measure of the brain's electrical activity~\cite{med_app}. The activity is governed by the Maxwell's Equations that can be reduced to the ODEs~\cite{DAUNIZEAU20092089}. The EEG can be used for detecting arrhythmias or other heart conditions~\cite{application_eeg_1} as well as to identify seizures and sleep stages from brainwave data~\cite{application_eeg_2}. In the weather forecasting the fundamental equations of atmospheric dynamics can also be reduced to an ODEs system~\cite{Kalnay_2002}. The classification problems in this field include weather regime classification~\cite{weather_regimes} and climate pattern identification~\cite{climate_regimes}. In human activity recognition (HAR) ODEs are primarily used to model the dynamics of human motion. The core idea is that human movement is a continuous physical process governed by laws of mechanics, which can be described by differential equations~\cite{ZHAO2021100114}. This idea can be applied to the basic or fine-grained activity recognition~\cite{Anguita2013APD, har_dl1}, fall detection~\cite{fall_detect}, and other tasks. To conclude, our model is applicable when it is reasonable to assume that observed time series come from some dynamical system of the form (\ref{eq:series_dyn}) or(\ref{eq:series_sde_dyn}).
		
		Our classifier will rely on the knowledge of the vector fields $f_j$ which is not always available. To compensate this we will build approximate fields from data using Neural Ordinary Differential Equations (NODE)~\cite{node}. It allows to use gradient optimization when an optimized objective depends on ODE trajectories. There are plenty of papers using NODE for regression tasks. For example, NODE are used in the context of the physics-informed ODE~\cite{LAI2021116196, phys_informed_2} and control learning~\cite{NEURIPS2019_99a40143, node_rl}. However, very few papers analyze NODE in the context of time series classification. Authors of~\cite{8892510} reinterpreted convolutional neural networks in terms of latent ODE dynamics and used it for hyperspectral image classification. Paper~\cite{node_control} solved classification problem in terms of control theory and NODE. Our paper contributes to the NODE applications for the general dynamical systems.
		  
		% NODE's time series model critique + novelty
		The NODE paper~\cite{node} introduced its own popular time series model called latent ODE. It is illustrated on the Fig.~\ref{fig:node_ts}. The model is probabilistic and in our terms it can be described as
		  
		 \begin{gather*}
		  \bbx_{t_0} \sim p_0(\bbx_{t_0}), \\
		  \bbx_{t_1}, \bbx_{t_2}, \ldots, \bbx_{t_N} = \text{ODESolve}(\bbx_{t_0}, f, t_0, \ldots, t_N), \\
		  \text{each } \bx_{t_i} \sim p_x(\bx_{t_i}|\bbx_{t_i})
		\end{gather*}
		  
		where $\text{ODESolve}()$ is an approximate solution of the initial value problem using ODE solver~\cite{bibid}. Authors used a variational autoencoder (VAE)~\cite{Kingma2013AutoEncodingVB} to inference the distributions $p_0, p_x$ and the vector field $f$ from the $\bx_{t_i}$. While this model is more general and is widely used~\cite{cnode, Herrera2020NeuralJO, Seedat2022ContinuousTimeMO}, it has several drawbacks compared to ours. First, it has to parameterize $f, p_x$ and the VAE. Hence, more data is needed in general to obtain good approximations of these functions. Our approach may only need to parameterize $f$. Second, in the latent ODE model a connection between the phase trajectories and the observed time series is given by the general distribution $p_x$. Thus, the connection is difficult to interpret. In addition, the VAE is needed to reconstuct the $\bbx(t_i)$ from the $\bx(t_i)$. Our reconstruction approaches discussed above give explicit and easy ways to obtain $\bbx(t_i)$ from the $\bx(t_i)$ and vice versa. Actually, several papers can be found in the literature~\cite{node_takens_1, node_takens_2} that use Takens theorem ideas with the NODE to restore latent dynamics. But unfortunately, it is poorly covered for machine learning applications. Our paper aims to close this gap.

		In the next section we will describe a general principal for the time series classification inside our model. We will build an asymptotically optimal classifier under mentioned properties of the noise $\epsilon_{t_i}$ and several additional conditions. These conditions will help with a theoretical prove but may not hold in practice. So we will progressively discard this conditions and adapt classifier for a more general settings. We will also show how adapt the classifier to the SDE case (\ref{eq:series_sde_dyn}). Finally, we will describe the procedure of building vector field approximations from the data. Then we will apply our method to three classification tasks for emprirical validation. The first will be the classification of several known chaotic~\cite{bibid} dynamical systems. The second will be classification of the human motions from the Inertial Measurement Unit (IMU) sensors. The last one will be classification of heart condition from the ECG recordings.
		
	\section{Asymptotically optimal classifier}
	
		The main principle for building a classifier in the paper is the proximity of an observed time series $\bx(t_i)$ to the theoretical initial value problem solution $\bbx(t | \bbx_0, f_j)$ for each class $j \in 1 \ldots K$. Basically, our classifier is distance-based.
		
		Denote by $\rho_n\big( \bx(t_i), \mathbf{y}(t_i) \big)$ the metric between time series $\bx(t_i)$, $\mathbf{y}(t_i)$ of length $n$ defined as 
		\begin{equation}\label{def:series_distance}
			\rho_n\big( \bx(t_i), \mathbf{y}(t_i) \big) = \sum\limits_{i=1}^n \lVert \bx(t_i) - \mathbf{y}(t_i) \rVert_2^2.
		\end{equation}
		Then, define the classifier as
		\begin{equation}\label{def:basic_classifier}
			\delta \big( \bx(t_i) \big) = \underset{j \in 1 \ldots K}{\arg\min} \ \rho_n\big( \bx(t_i), \bbx(t_i | \bbx_0, f_j) \big).
		\end{equation}
		It turns out that this theoretical classifier has vanishing probability of misclassification as the length of the time series increases. But starting point $\bbx_0$ must be known exactly and phase trajectories from different systems must diverge in some sense. The formal result:
		\begin{Th}\label{thm:asympt_optimal}
			Let $\bx(t_i)= \{\bx_{t_1}, \ldots, \bx_{t_n}\}$ be the time series to classify defined for all $n \in \mathbb{N}$. Let $\bbx_0$ be the starting point of the associated phase trajectory $\bbx(t_i)$. And let
			\begin{equation*}
				\rho_{\infty} \big( \bbx(t | \bbx_0, f_j), \bbx(t | \bbx_0, f_p) \big) = +\infty \ \forall j \not= p; \ j,p \in 1 \ldots K.
			\end{equation*}
			Denote by $y$ the true class of the time series. Then, under proposed conditions on the noise (\ref{eq:noise_conditions}), the following holds
			\begin{equation*}
				\mathbb{P}(\delta \big( \bx(t_i) \big) \not= y)  \to 0, \  n \to \infty.
			\end{equation*}
		\end{Th}
		The proof of the theorem is deferred to Appendix \ref{app:proofs}.
	
	\section{Why optimal classifier may be intractable}\label{sec:cls_problems}
	
		Unfortunately, the classifier (\ref{def:basic_classifier}) relies on precise IVP solutions and Theorem \ref{thm:asympt_optimal} relies on precise starting point $\bbx_0$. These requirements are often too strong on practice. We now provide several reasons for that and propose a new classifier.
		
		\subsection{Approximate vector fields}
		
			Imagine instead of the true vector fields $f_j$ we only have approximate versions $\tilde{f}_j$ such that
			\begin{equation*}
				\lVert f_j - \tilde{f}_j \rVert \le r_j,
			\end{equation*}
			where $f_j, \tilde{f}_j \in \mathcal{F}(M)$ and $r_j$ are approximation error bounds. This situation always rises when one approximates vector fields from the data (see Section \ref{sec:learn_ode}).
			
			In general, any small approximation error is enough for phase trajectories from $f$ and $\tilde{f}$ to diverge. We show an Example \ref{ex:approx_pathology} of such system in Appendix \ref{app:proofs}. The visualization of the associate trajectories is on the Fig. \ref{fig:approx_pathology}  That makes classifier (\ref{def:basic_classifier}) useless. Nonetheless, for a large family of vector fields the $\bbx(t | \bbx_0, \tilde{f}_j)$ are arbitrary close to $\bbx(t | \bbx_0, f_j)$ if $r_j$ is sufficiently small and times are bounded $t < T$. This is called Grönwall-type bounds and can be found in ODE literature~\cite{arnold1992ordinary}. So further we assume approximation errors are small enough and vector fields $f_j$ are considerably different to not differentiate between $\bbx(t | \bbx_0, \tilde{f}_j)$ and $\bbx(t | \bbx_0, f_j)$. We also assume that vector fields $f_j$ are considerably different across classes to exclude situations like in Example \ref{ex:approx_pathology}.
			\begin{figure}[h]
				\centering
				\includegraphics[width=\textwidth, keepaspectratio]{diverging_systems}
				
				\caption{Diverging phase trajectories of the close vector fields $\lVert f - \tilde{f} \rVert \le 0.1$ with $\bbx_0 = (0, 1)^{\text{T}}$. While $\bbx(t | \bbx_0, f)$ is a circle trajectory (called center in dynamical systems), the $\bbx(t | \bbx_0, \tilde{f})$ is a spiral sink that diverges to the $\mathbf{0}$.}\label{fig:approx_pathology}
			\end{figure}
			
		\subsection{Approximate IVP solutions and noisy phase trajectories}
			
			Even if vector fields are known exactly, the IVP is almost always intractable~\cite{bibid}. The numerical methods called ODE solvers are able to approximate IVP solution with arbitrary precision~\cite{bibid} for regular vector fields. The main approximation parameter of the solvers is an integration step $\tau$. A solver has order of convergence $l$ if
			\begin{equation}\label{eq:converg_order}
				 \underset{t \in [0, T]}{\sup} \left| \text{ODESolve}(t | \bbx_{t_0}, f) - \bbx(t | \bbx_0, f) \right| = \mathcal{O}(T \tau^l).
			\end{equation}
			The higher the convergence order and the smaller $\tau$ the higher computational complexity of the ODESolve procedure. Besides this tradeoff some vector fields imply additional constraints on the smallness of the $\tau$. If not satisfied, solver solution diverges from the true one. This effect is called \emph{stiffness} and is usually addressed by choosing an appropriate solver~\cite{bibid}. The illustration of this effect is on the Fig. \ref{fig:stiffness}.

			\begin{figure}[h!]
				\centering
				\includegraphics[width=\textwidth, keepaspectratio]{stiffness_illustration}
				\caption{Exact and approximate IVP solutions for the stiff system $f(\bbx) = \begin{pmatrix}
						-35 & 0 \\
						0 & 0.5
					\end{pmatrix} \bbx$ and $\bbx_0 = (1000, 1)^{\text{T}}$. The Runge-Kutta23 (RK23) ODE solver approximates exact solution with high precision. The Euler (euler) ODE solver is unstable and diverges from the exact solution. Integration step $\tau = 0.05$ is equal for both solvers but for Euler it is not small enough. The RK23 has higher convergence order and is stable under such $\tau$.
				}\label{fig:stiffness}
			\end{figure}

			As follows from (\ref{eq:converg_order}) applying ODESolve to find full trajectory $t \in [0, T]$ starting from the exact $\bbx_0$ becomes impractical for long trajectories. We also assume
			\begin{equation}\label{eq:random_start_p}
				\bbx_0 \sim F(\cdot)
			\end{equation}
			to be a random vector in general where $F(\cdot)$ is its distribution function. Hence, the classifier \ref{def:basic_classifier} can not be applied in these conditions.
			
			On the other hand, imagine we knew $\bbx_0$ and $\bbx_{t_i}$ for some $i \in 1 \ldots n$. We could then approximate $\bbx(t | \bbx_0, f), t \in [0, t_i)$ using $\text{ODESolve}(t | \bbx_{t_0}, f)$, and approximate $\bbx(t | \bbx_0, f), t \in [t_i, T]$ using $\text{ODESolve}(t | \bbx_{t_i}, f)$. The solver's accuracy increases. To obtain practical solution, we could simply replace $\bbx_{t_i}$ with $\bx_{t_i}$. But if the $\sigma$ from (\ref{eq:noise_conditions}) is large enough then the starting points differ considerably with high probability. This leads to very different IVP solutions $\text{ODESolve}(t | \bx_{t_i}, f), \text{ODESolve}(t | \bbx_{t_i}, f)$ in general~\cite{bibid}. We must take randomness into account in a different way.
	
	\section{Classification as smoothing problem}
	
		Let's break dynamics (\ref{eq:series_dyn}) into consecutive time segments  $[t_0, t_1), [t_1, t_2), \ldots, [t_{n-1}, t_n]$ so we have $n$ IVPs
		\begin{equation}
			\begin{cases}\label{eq:seg_series_dyn}
				\frac{d}{dt} \bbx(t) = f(\bbx), \\
				\bbx(0) = \bbx_{t_i}, \\
				t \in [0, t_{i+1} - t_i].
			\end{cases}
		\end{equation}
		Let's approximate each IVP solution by the ODESolve so $\bbx_{t_{i+1}} = \text{ODESolve}(t_{i+1} - t_i | \bbx_{t_i}, f)$. Combining with the (\ref{eq:series_def}) and (\ref{eq:random_start_p}) we obtain discrete dynamics
		\begin{equation}\label{eq:smooth}
			\begin{cases}
				\bbx_{t_{i+1}} = \text{ODESolve}(t_{i+1} - t_i | \bbx_{t_i}, f), \\
				\bx_{t_i} = \bbx_{t_i} + \beps_{t_i}, \\
				\bbx_0 \sim F(\cdot).
			\end{cases}
		\end{equation}
		The $\bx(t_i)$ is observed, everything else is not. To adapt classifier \ref{def:basic_classifier} for this model we need to substitute intractable $\bbx(t_i | \bbx_0, f)$ for the best approximation based on random $\bbx_0$ and $\bx_{t_i}, i \in 1 \ldots n$. If we take an $L_2$ norm in the space of random vectors, the best approximation is \emph{conditional expectation}~\cite{bibid}. We denoted a series of conditional expectations by $\mathbb{E}[\bbx(t_i) | \bbx_0, \bx(t_i), f]$ that means $i$-th series value is $\mathbb{E}[\bbx_{t_i} | \bbx_0, \bx_{t_1}, \ldots, \bx_{t_n}]$. The problem of finding $\mathbb{E}[\bbx(t_i) | \bbx_0, \bx(t_i), f]$ is called the \emph{smoothing problem}. On the one hand, it is intractable in general~\cite{bibid} similarly to the IVP. On the other hand, there are numerical methods for obtaining approximate solutions. Some of them are extensions of the Kalman filer~\cite{bibid}. Another are based on the bayessian~\cite{bibid} and particle~\cite{bibid} filters. Solving the smoothing problem is an active research area~\cite{bibid}.
		
		The new classifier is defined as
		\begin{equation}\label{def:new_classifier}
			\delta \big( \bx(t_i) \big) = \underset{j \in 1 \ldots K}{\arg\min} \ \rho_n\big( \bx(t_i), \mathbb{E}[\bbx(t_i) | \bbx_0, \bx(t_i), f_j] \big).
		\end{equation}
		The classifier now relies not only on the dynamics driven by the vector fields $f_j$ but also on the observations $\bx(t_i)$. This mitigates problems discussed in the Section \ref{sec:cls_problems}:
		\begin{enumerate}
			\item Inaccuracy from the approximate $\tilde{f}$ and ODESolve decreases because we give up the full IVP $t \in [0, T]$ in favor of the smaller IVPs on time segments $t \in [t_{i+1}, t_i]$.
			\item Randomness of the $\bbx_0, \bx_{t_i}$ is taken into account via the conditional expectation $\mathbb{E}[\bbx(t_i) | \bbx_0, \bx{t_i}, f]$. Informally, it optimally balances the underlying dynamics (\ref{eq:series_dyn}) with the noisy observations to approximate the IVP solution $\bbx(t_i | \bbx_0, f)$.
		\end{enumerate}
		
		Comparison of the IVP $\bbx(t_i | \bbx_0, f)$ approximation by $\text{ODESolve}(t_i | \bbx_{t_0}, f)$ and by $\mathbb{E}[\bbx(t_i) | \bbx_0, \bx(t_i), f]$ is illustrated on the Fig. \ref{fig:odeint_vs_smooth}.

			\centering
			\includegraphics[width=\textwidth, keepaspectratio]{ode_cls_compare}

	\section{Adapting classifier for SDE}
	
		We can segment dynamics (\ref{eq:series_sde_dyn}) similarly to the (\ref{eq:seg_series_dyn}) and obtain
		\begin{equation}
			\begin{cases}\label{eq:seg_series_dyn}
				d\bbx(t) = f(\bbx)dt + G dW(t), \\
				\bbx(0) = \bbx_{t_i}, \\
				t \in [0, t_{i+1} - t_i].
			\end{cases}
		\end{equation}
		If all time segments are small enough, we can approximate dynamics $f(\bbx)dt \approx \text{ODESolve}(t_{i+1} - t_i | \bbx_{t_i}, f)$ and $G dW(t) \approx G \cdot \mathcal{N}(0, (t_{i+1} - t_i) \cdot  I) = \mathcal{N}(0, (t_{i+1} - t_i) \cdot G G^{\text{T}}) := \xi_{t_{i+1}}$. As a result, we obtain discrete dynamics akin to (\ref{eq:smooth}):
		\begin{equation}\label{eq:smooth_sde}
			\begin{cases}
				\bbx_{t_{i+1}} = \text{ODESolve}(t_{i+1} - t_i | \bbx_{t_i}, f) + \xi_{t_{i+1}}, \\
				\bx_{t_i} = \bbx_{t_i} + \beps_{t_i}, \\
				\bbx_0 \sim F(\cdot).
			\end{cases}
		\end{equation}
		Finding $\mathbb{E}[\bbx(t_i) | \bbx_0, \bx(t_i), f]$ here is just a more general smoothing problem and can be solved by the same methods listed above. The classifier (\ref{def:new_classifier}) for the SDE case stays the same. Comparison of the different SDE IVP $\bbx(t_i | \bbx_0, f)$ approximation is given on the Fig. \ref{fig:odeint_vs_smooth_sde}.
		
		\begin{figure}[h!]
			\centering
			\includegraphics[width=\textwidth, keepaspectratio]{sde_cls_compare}
			
			\caption{Different IVP approximations for the one-dimensional system $dx(t) = x dt + dW(t)$. The initial value $x_0 \sim \mathcal{N}(1, 1)$ and $\beps_{t_i} \sim \mathcal{N}(0, 1)$. Phase trajectory is a random process here in contrast to the ODE dynamics. ODESolve uses Euler solver with initial value $\mathbb{E}[x_0] = 1$. We can see it is inadequate model for the SDE dynamics. Stepwise ODESolve uses Euler solver on consecutive time segments $[t_i, t_{i+1})$ with noisy initial values $x_{t_i}$. It is more accurate but is subject to the noise and still misses $dW(t)$ term. 		\end{figure}
	
	\section{Learning vector field from data}\label{sec:learn_ode}
	
		Sometimes vector field $f$ may be unknown. Instead, time series samples from the associate dynamics (\ref{eq:series_dyn}) may be available. From the (\ref{eq:series_dyn}) and (\ref{eq:series_def}) we have
		\begin{equation*}
			\bx_{t_i} = \bbx(t_i | \bbx_0, f) + \beps_{t_i} \ i \in 1 \ldots n
		\end{equation*}
		where $\bbx_0$ is defined as in (\ref{eq:random_start_p}). Approximating the true IVP by the ODESolve we obtain
		\begin{equation*}
			\bx_{t_i} =  \text{ODESolve}(t_i | \bbx_0, f) + \beps_{t_i} \ i \in 1 \ldots n.
		\end{equation*}
		By taking the expectation from both sides and gathering the terms on the left-hand side we get
		\begin{equation*}
			\mathbb{E} \left[ \bx_{t_i} -  \text{ODESolve}(t_i | \bbx_0, f) \right]  = 0 \ i \in 1 \ldots n.
		\end{equation*}
		We can apply \emph{generalized method of moments}~(GMM)~\cite{bibid} here. Assume we have a set of vector fields $\mathcal{S}_{\Theta} \subset \mathcal{F}(M)$ parameterized by the real vector $\Theta$. Assume $f \in \mathcal{S}_{\Theta}$. Denote the solution of the following optimization problem
		\begin{equation}\label{eq:mse_min}
			\sum\limits_{i=1}^n \big(  \bx_{t_i} -  \text{ODESolve}(t_i | \bbx_0, f) \big)^2 \to \underset{f \in \mathcal{S}_{\Theta}}{\min}
		\end{equation}
		as $f_{\hat{\Theta}}$. Here $\bbx_0, \bx_{t_i}  \ i \in 1 \ldots n$ are sampled values. If some technical conditions on $\theta$ holds~\cite{bibid}, the GMM guarantees that
		\begin{equation}\label{eq:gmm_guarant}
			f_{\hat{\Theta}} \xrightarrow{\mathbb{P}} f, \ n \to \infty.
		\end{equation}
		The (\ref{eq:mse_min}) can be solved using NODE. As discussed in the Section \ref{sec:cls_problems}, $n$ should not be large due to approximation errors of the ODESolve. Instead, it is better to sample $N$ short batches $ B = \big( \bbx_0, \{\bx_{t_i} \}_{i=1}^n \big)$ and solve
		\begin{equation}\label{eq:mse_min_batch}
			\sum\limits_{j=1}^N \sum\limits_{\bbx_0, \bx_{t_i} \in B_j} \big(  \bx_{t_i} -  \text{ODESolve}(t_i | \bbx_0, f) \big)^2 \to \underset{f \in \mathcal{S}_{\Theta}}{\min}
		\end{equation}
		which is equivalent to (\ref{eq:mse_min}) in terms of the convergence (\ref{eq:gmm_guarant}).
		
		SDE dynamics (\ref{eq:series_sde_dyn}) can also be learned from the data by the methods similar to NODE~\cite{pmlr-v108-li20i, NEURIPS2021_9ba196c7}.

	\section{Empirical study}\label{Experiment}

		In this section we validate the proposed classifier (\ref{def:new_classifier}) on three classification tasks of progressively decreasing prior knowledge about the underlying dynamics. In the second task the fields are unknown and are learned from data with NODE as described in Section \ref{sec:learn_ode}. The dataset for this task is \href{https://www.timeseriesclassification.com/description.php?Dataset=ECG5000}{ECG5000}~\cite{bibid}.

		\subsection{Linear dynamical systems}\label{sec:exp_chaotic}
		
			The first task classifies trajectories generated by three linear ODE systems with the following form
			\begin{equation}\label{eq:synth_exp_vf}
				f(\bbx) = A \bbx = U \Lambda U^{\text{T}} \bbx = U  \begin{pmatrix}
					-\gamma_1 & w & 0 \\
					-w & -\gamma_1 & 0 \\
					0 & 0 & -\gamma_2

Vector field (\ref{eq:synth_exp_vf}) simulates damped oscillation along first two eigenvectors and exponential decay along the third. We used $\gamma_1 = 0.7, \gamma_2 = 0.6, w = 4.$. For each class we sample $\bbx_0 \sim \mathcal{N}(\mathbf{0}, 4 \cdot I)$ and integrate the system trajectories of length $n=100$ with step $\tau=0.05$. Then we corrupt them with additive Gaussian noise of level $\sigma=2.$ following (\ref{eq:series_def})--(\ref{eq:noise_conditions}). The visualization of the final series and underlying phase trajectories is on the Fig. \ref{fig:linear_systems} (with lower noise level for clearer illustration).

			\begin{proof}[Proof of Theorem \ref{thm:asympt_optimal}]
				First, estimate conditional probability of the misclassification
				\begin{multline*}
					\mathbb{P}(\delta \big( \bx(t_i) \big) = j | y = p) = \mathbb{P}\big[ \bigcap_{s = 1, s \not=j}^{K} \{ \rho_n\big( \bx(t_i), \bbx(t | \bbx_0, f_j) \big) < \rho_n\big( \bx(t_i), \bbx(t | \bbx_0, f_s) \big) \} \big] \le \\ |\text{ monotonicity of probability }| \le \mathbb{P}\big[ \rho_n\big( \bx(t_i), \bbx(t | \bbx_0, f_j) \big) < \rho_n\big( \bx(t_i), \bbx(t | \bbx_0, f_p) \big) \big].
				\end{multline*}
				Expand metrics in the last event using $y = p$:
				\begin{equation*}
					\rho_n\big( \bx(t_i), \bbx(t | \bbx_0, f_p) \big) = \sum\limits_{i=1}^n \lVert  \bx(t_i) - \bbx(t | \bbx_0, f_p)  \rVert^2 = \sum\limits_{i=1}^n \lVert \beps_{t_i} \rVert^2,
				\end{equation*}
				\begin{multline*}
					\rho_n\big( \bx(t_i), \bbx(t | \bbx_0, f_j) \big) = \sum\limits_{i=1}^n \lVert  \bx(t_i) - \bbx(t | \bbx_0, f_j)  \rVert^2 = \sum\limits_{i=1}^n \lVert \big( \bbx(t | \bbx_0, f_p) - \bbx(t | \bbx_0, f_j) \big) + \beps_{t_i} \rVert^2 = \\ = \sum\limits_{i=1}^n \lVert \bbx(t | \bbx_0, f_p) - \bbx(t | \bbx_0, f_j) \rVert^2 + 2 \sum\limits_{i=1}^n \langle \bbx(t | \bbx_0, f_p) - \bbx(t | \bbx_0, f_j) , \beps_{t_i} \rangle + \sum\limits_{i=1}^n \lVert \beps_{t_i} \rVert^2.
				\end{multline*}
				Here $\langle \cdot, \cdot \rangle$ is the standard scalar product. The last event is now
				\begin{gather*}
					\rho_n\big( \bx(t_i), \bbx(t | \bbx_0, f_i) \big) < \rho_n\big( \bx(t_i), \bbx(t | \bbx_0, f_j) \big) \Leftrightarrow \\
					\sum\limits_{i=1}^n \langle \bbx(t | \bbx_0, f_p) - \bbx(t | \bbx_0, f_j) , \beps_{t_i} \rangle < - \frac{1}{2} \sum\limits_{i=1}^n \lVert \bbx(t | \bbx_0, f_p) - \bbx(t | \bbx_0, f_j) \rVert^2 \Leftrightarrow \\
					\sum\limits_{i=1}^n \langle \bbx(t | \bbx_0, f_p) - \bbx(t | \bbx_0, f_j) , \beps_{t_i} \rangle < - \frac{1}{2} \rho_{n} \big( \bbx(t | \bbx_0, f_j), \bbx(t | \bbx_0, f_p) \big).
				\end{gather*}
				Apply Markov inequality and use (\ref{eq:noise_conditions}):
				\begin{multline*}
					\mathbb{P}\big[ \rho_n\big( \bx(t_i), \bbx(t | \bbx_0, f_j) \big) < \rho_n\big( \bx(t_i), \bbx(t | \bbx_0, f_p) \big) \big] \le 4 \frac{\mathbb{D}\big[ \sum\limits_{i=1}^n \langle \bbx(t | \bbx_0, f_p) - \bbx(t | \bbx_0, f_j) , \beps_{t_i} \rangle \big]}{\rho^2_{n} \big( \bbx(t | \bbx_0, f_j), \bbx(t | \bbx_0, f_p) \big)} = \\ = 4 \frac{\sum\limits_{i=1}^n \mathbb{E} \big[ \langle \bbx(t | \bbx_0, f_p) - \bbx(t | \bbx_0, f_j) , \beps_{t_i} \rangle^2 \big]}{\rho^2_{n} \big( \bbx(t | \bbx_0, f_j), \bbx(t | \bbx_0, f_p) \big)} = \\ = 4 \frac{\sum\limits_{i=1}^n \big( \bbx(t | \bbx_0, f_p) - \bbx(t | \bbx_0, f_j) \big)^{\text{T}} \mathbb{E} \big[ \beps_{t_i} \beps_{t_i}^{\text{T}} \big] \big( \bbx(t | \bbx_0, f_p) - \bbx(t | \bbx_0, f_j) \big)}{\rho^2_{n} \big( \bbx(t | \bbx_0, f_j), \bbx(t | \bbx_0, f_p) \big)} = \\ = 4 \frac{\sum\limits_{i=1}^n \big( \bbx(t | \bbx_0, f_p) - \bbx(t | \bbx_0, f_j) \big)^{\text{T}} R \big( \bbx(t | \bbx_0, f_p) - \bbx(t | \bbx_0, f_j) \big)}{\rho^2_{n} \big( \bbx(t | \bbx_0, f_j), \bbx(t | \bbx_0, f_p) \big)} = \\ = 4 \frac{\sum\limits_{i=1}^n \langle \bbx(t | \bbx_0, f_p) - \bbx(t | \bbx_0, f_j) \big)^{\text{T}}, R \big( \bbx(t | \bbx_0, f_p) - \bbx(t | \bbx_0, f_j) \rangle}{\rho^2_{n} \big( \bbx(t | \bbx_0, f_j), \bbx(t | \bbx_0, f_p) \big)} \le \\ \le 4 \sigma^2 \frac{\sum\limits_{i=1}^n \lVert \bbx(t | \bbx_0, f_p) - \bbx(t | \bbx_0, f_j) \rVert^2}{\rho^2_{n} \big( \bbx(t | \bbx_0, f_j), \bbx(t | \bbx_0, f_p) \big)} = 4 \sigma^2 \frac{\rho_{n} \big( \bbx(t | \bbx_0, f_j), \bbx(t | \bbx_0, f_p) \big)}{\rho^2_{n} \big( \bbx(t | \bbx_0, f_j), \bbx(t | \bbx_0, f_p) \big)} = \frac{4 \sigma^2}{\rho_{n} \big( \bbx(t | \bbx_0, f_j), \bbx(t | \bbx_0, f_p) \big)} := \xi_n.
				\end{multline*}
			By theorem condition we have
			\begin{equation*}
				\rho_{n} \big( \bbx(t | \bbx_0, f_j), \bbx(t | \bbx_0, f_p) \big) \to \rho_{\infty} \big( \bbx(t | \bbx_0, f_j), \bbx(t | \bbx_0, f_p) \big) = +\infty, \  n \to \infty
			\end{equation*}
			so $\xi_n \to 0, \ n \to \infty$ for all $j,p \in 1 \ldots K$.
			
			Second, rewrite probability of the misclassification via conditional probability:
			\begin{multline*}
				\mathbb{P}(\delta \big( \bx(t_i) \big) \not= y) = \mathbb{E}_y \big[ \sum\limits_{p=1}^K \mathbb{P}(\delta \big( \bx(t_i) \big) \not= p | y = p) \big] = \mathbb{E}_y \big[ \sum\limits_{p=1}^K \mathbb{P}( \bigcup_{j = 1, j \not=p}^{K} \{ \delta \big( \bx(t_i) \big) = j | y = p \} ) \big] \le \\ |\text{ union bound }| \le \mathbb{E}_y \big[ \sum\limits_{p=1}^K \sum\limits_{j = 1, j \not=p}^K \mathbb{P}( \delta \big( \bx(t_i) \big) = j | y = p) \big] \le \sum\limits_{p=1}^K \sum\limits_{j = 1, j \not=p}^K \xi_n = K (K - 1) \xi_n \to 0.
			\end{multline*}
			\end{proof}
			
			\begin{Ex}\label{ex:approx_pathology}
				Here we construct a system of two arbitrary close vector fields with diverging phase trajectories.
				Let $M = \{\bbx \in \mathbb{R}^2 \mid \lVert \bbx \rVert_2 \le R\}$ be a plane circle. Define the vector field's norm as a sup norm
				\begin{equation*}
					\lVert f \rVert = \underset{\bbx \in M}{\sup} \lVert f(\bbx) \rVert_2.
				\end{equation*}
				Let $\bbx_0 = c \cdot (\cos \gamma, \sin \gamma)^{\text{T}} \not= \mathbf{0}$ be an initial value. Let $\{t_i\}_{i=1}^{\infty}$ be any time sequence and let $r> 0$ be an arbitrary small value. Construct two vector fields
				\begin{gather*}
					f(\bbx) = \begin{pmatrix}
						\mathrm{i} a & 0 \\
						0 & \mathrm{i} a
					\end{pmatrix} \bbx = A \bbx, \\
					\tilde{f}(\bbx) = \begin{pmatrix}
						\mathrm{i} a - b& 0 \\
						0 & \mathrm{i} a - b
					\end{pmatrix} \bbx = \tilde{A} \bbx
				\end{gather*}
				where $\mathrm{i}$ is an imaginary unit, $a \not= 0, b > 0$ are some scalars.  Then
				\begin{equation*}
					\lVert f - \tilde{f} \rVert \le \lVert A - \tilde{A} \rVert_2 \cdot \lVert x\rVert  = \lVert \begin{pmatrix}
						b & 0 \\
						0 & b
					\end{pmatrix} \rVert_2 \cdot \lVert x \rVert \le b R
				\end{equation*}
				where $\lVert A - \tilde{A} \rVert_2$ is matrix spectral norm. So if $b < \dfrac{r}{R} $ then $\lVert f - \tilde{f} \rVert < r$.
				Next, it easy to obtain that IVP solutions for the ODE systems are
				\begin{gather*}
					\bbx(t | \bbx_0, f) = c \begin{pmatrix}
						\sin (\gamma - at) \\
						\cos (\gamma - at)
					\end{pmatrix}, \\
					\bbx(t | \bbx_0, \tilde{f}) = c \exp(-bt) \begin{pmatrix}
						\sin (\gamma - at) \\
						\cos (\gamma - at)
					\end{pmatrix}.
				\end{gather*}
				It is obvious that $\bbx(t | \bbx_0, \tilde{f}) \to \mathbf{0}, t \to \infty$ and $\lVert \bbx(t | \bbx_0, \tilde{f}) \rVert = \lVert \bbx_0\rVert = c \   \forall t$. So
				\begin{equation*}
					\lVert \bbx(t_i | \bbx_0, f) - \bbx(t_i | \bbx_0, \tilde{f}) \rVert \to c \not=0, \ i \to \infty
				\end{equation*}
				and then 
				\begin{equation*}
					\rho_n\big( \bbx(t_i | \bbx_0, f), \bbx(t_i | \bbx_0, \tilde{f}) \big) = \sum\limits_{i=1}^n \lVert \bbx(t_i | \bbx_0, f) -  \bbx(t_i | \bbx_0, \tilde{f}) \rVert_2^2 \to \infty, \ n \to \infty
				\end{equation*}
				by the absence of the necessary condition for series convergence.
				
				As a result, classifier (\ref{def:basic_classifier}) that uses $\bbx(t_i | \bbx_0, \tilde{f})$ do not have guarantees of the Theorem \ref{thm:asympt_optimal} even though $f$ and $\tilde{f}$ are arbitrary close.
			\end{Ex}
